# نظام إدارة المخزون — Inventory Management System

مشروع مقرر تقنيات الويب المتقدمة (CIT1303/CIT430) — جامعة تبوك.
مبني بـ PHP (PDO) + MySQL، بواجهة عربية RTL.

## خطوات التشغيل
1. أنشئ قاعدة بيانات فارغة (مثلاً `inventory_db`) من لوحة الاستضافة / phpMyAdmin.
2. عدّل ملف `config.php` (DB_HOST, DB_NAME, DB_USER, DB_PASS).
3. ارفع كل الملفات إلى الاستضافة (مجلد htdocs أو public_html).
4. افتح `install.php` في المتصفح مرة واحدة: ينشئ الجداول والحسابات وبيانات تجريبية.
5. احذف `install.php` بعد التثبيت.
6. سجّل الدخول: مدير `admin / admin123` — موظف `staff / staff123`.

> بديل: استورد `database.sql` يدوياً من phpMyAdmin ثم شغّل `install.php` لإضافة الحسابات.

## الصفحات
| الصفحة | الوظيفة |
|---|---|
| index.php | لوحة التحكم (مؤشرات، منخفض الكمية، آخر الحركات) |
| products.php | عرض المنتجات + بحث وتصفية + حذف |
| product_form.php | إضافة / تعديل منتج |
| stock.php | إدخال وإخراج كميات وسجل الحركات |
| reports.php | 4 تقارير + طباعة + تصدير CSV |
| categories.php | CRUD للتصنيفات (مدير) |
| users.php | CRUD للمستخدمين والصلاحيات (مدير) |

## الصلاحيات
- **المدير**: كل شيء (حذف المنتجات، التصنيفات، المستخدمون).
- **الموظف**: عرض/إضافة/تعديل المنتجات، حركة المخزون، التقارير.

## الأمان
PDO Prepared Statements، `password_hash`، حماية CSRF، `htmlspecialchars` لكل المخرجات، `session_regenerate_id`.

## لقطات مطلوبة للتقرير (PDF)
- بنية قاعدة البيانات من phpMyAdmin (الجداول الأربعة + المخطط Designer)
- تسجيل الدخول، لوحة التحكم، المنتجات، إضافة/تعديل منتج، حركة المخزون، التقارير، التصنيفات، المستخدمون
- تحت كل لقطة وصف قصير.
